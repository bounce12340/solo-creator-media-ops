# Post copy

## Language order (default)
- For a video with `<VOICEOVER_LANGUAGE>` voiceover, every platform's caption
  starts with that language, then the secondary language in the next
  paragraph. Reference setup: English first, then Traditional Chinese.

## AI-voiceover label
- The "AI voiceover" label goes only where the platform asks for it
  **(default: TikTok and YouTube)**. Do not add it to Instagram, Threads, X
  or LinkedIn. Check each platform's current AI-content policy; it changes.

## Credits and links
- When the video is based on someone else's video, every post links the
  original and credits the original author.
- Music credit: add it when available. A missing music credit does not block
  publishing.

## Per-platform notes
- **Instagram / Facebook:** caption file inserted in one go, read back and
  compared to the file. Note the "share to Facebook" toggle state.
- **Threads:** split into parts under 500 characters each, saved as separate
  numbered files. Each part is posted as a reply to the previous part using
  the full reply dialog.
- **X:** a regular post is at most 280 weighted characters (CJK characters,
  full-width punctuation and emoji count 2; URLs count 23). Long posts may run
  longer but the first paragraph must stand alone. At most 2 hashtags on long
  posts. Mentions that should notify someone go in the first 280 characters;
  never start a post with a mention. Post the first reply (with the source
  link) only after the main post is final.
- **YouTube Shorts / TikTok / LinkedIn:** platform-specific length and tone;
  the fact editor checks each version separately.

## Style
- Write like a person: cut filler openers ("In today's fast-paced world"),
  fake contrasts ("It's not just X, it's Y"), hype words (game-changer,
  unlock, supercharge, delve, seamless). Keep facts, qualifiers and
  attribution when rewriting. Direct quotes stay as the speaker said them.
- Keep a per-language "AI-tell" pattern list in your config and let the fact
  editor flag hits with the pattern code and a suggested fix.
- No analogy unless it clarifies something the plain sentence cannot.
