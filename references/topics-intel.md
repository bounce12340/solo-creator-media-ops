# Topics and intel

## Topic dedupe (before recommending anything)
1. Write a match key for each topic: **original source link + speaker/author**.
2. Compare with the published log and the publish queue. If the log row lacks
   the source link, look it up in that item's draft folder.
3. Label each topic:
   - **New**: link never used. Same speaker, new episode also counts as new.
   - **Possibly done**: same interview or post under another title, cut or
     repost. Point to the matching row and say how it differs.
   - **Done**: same link already published or queued. Point to the row; do
     not recommend it.
4. If a log file cannot be read, put "NOT DEDUPED" at the top and say which
   file failed.

## Weekly topic scout
- Look at the last 14 days from the sources in the topic list
  (`<TOPIC_AREAS>`, `<TRUSTED_SOURCES>`). Skip pure ads, reposts and
  second-hand summaries.
- For each: title, speaker, link, date, length, one-line core point, the best
  opening quote with timestamp (or "none"), dedupe label, licence risk, one
  reason to make it.
- Rank by fit with the topic list, then heat (views, reposts), then whether
  there is a strong first-3-seconds clip. Take the top 8.
- Numbers come from the page only. A source that will not open is written
  as "data missing", never filled from memory.

## Benchmark accounts
Split benchmark accounts into two columns:
- **Learnable:** close enough in size and format that their tactics can be
  copied (for example, within roughly one order of magnitude of the
  creator's following, same format).
- **Trend-only:** much bigger accounts; read them for what topics are moving,
  not for tactics.
Record follower counts with the date you read them. Re-check the split when
the creator's account grows.

## Daily intel report
- Short list of leads with source links and dedupe labels.
- On a day with nothing new, write **"No update" (`無更新`)** instead of
  padding the report.
