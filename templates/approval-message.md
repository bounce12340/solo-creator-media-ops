# Approval message (Action / Target / Reason)

Ask one decision at a time. Three lines, nothing else above them.

```
Action / 動作: <what exactly will happen, e.g. publish item 2026-11-03 to IG, Threads, X, YouTube>
Target / 對象: <which account, platform, file or person is affected>
Reason / 理由: <why now, with source link, cost and risk>
```

Example

```
Action / 動作: Reply to a comment asking about sponsorship pricing
Target / 對象: X reply under the 11/03 video, from <YOUR_HANDLE>
Reason / 理由: Money/collab topics need your call; proposed text: "Thanks! Please email <CONTACT_EMAIL>."
```
